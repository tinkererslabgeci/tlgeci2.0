# Tinkerers’ Lab Website

A faster, leaner, more secure, and better quasi-dynamic website for Tinkerers’ Lab at GEC
Idukki using Cloudflare Workers, Hugo, and GAS. This rewriting aims to surmount the
shortcomings of the previous website being clumsy, resource-heavy, lack of
maintainability, and longer-than-favourable page-rendering time.

Maintained by the Outreach Team. \
TL GECI, 2026.
